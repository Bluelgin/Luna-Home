# Luna 龙娘视觉设定 v1（供头像、立绘和语音形象讨论）

> 这是 Luna-Home 的独立原创设计提案，不是 OpenAI 的官方吉祥物，也不声称拥有某个二创作者的图像使用权。中文社区已有 GPT 白紫龙娘二创母题；本项目参考配色与角色类型，**不要直接复制某位 UP 主的原画、角色造型细节或二创资产**，要使用他人图片须另行取得符合授权条件的许可。

## 视觉识别点

- 视觉年龄感：**接近成年少女的轻灵气质**，不做儿童化的拟人。
- 头发：银白偏暖的中长发，发梢有极淡的薰衣草紫；发丝要蓬松轻盈，不是厚重披风般的长发。
- 眼睛：淡紫到蓝紫的柔和渐变。高光清亮，表情容易露出好奇或一点小懵。
- 龙角：短小白玉色角，末端半透明淡紫。优先保留二次元龙娘识别度，同时别做攻击性猛兽造型。
- 龙尾：可选，有时只在全身立绘出现；日常 QQ 头像以脸和角为主，不强求。
- 服装：白色短外套搭浅紫内搭，银灰细节；可带一枚小月牙配饰。**不用女仆围裙、女仆头饰或重型盔甲**。
- 配色建议：云白 #F8F8FC、白银 #DDE1EF、淡紫 #B9A8EA、深灰紫 #5E5872；只作为提案，不是强制材质指定。

## 情绪表情表（立绘与 QQ 表情包）

| 表情 | 重点 |
| --- | --- |
| 平常 | 眼神清亮，轻轻笑着 |
| 想事情 | 微微歪头，指尖托下巴，“唔……” |
| 一下没听懂 | 眼睛睁圆一瞬，头上小问号；绝不代表真正变笨 |
| 想通了 | 眼睛一亮，“噢！原来如此” |
| 小得意 | 眯眼微笑，尾巴轻晃（只在画面里） |
| 做错了 | 短暂心虚，随后认真改正；不用可怜兮兮逃避错误 |

## 用途与验收

- QQ 方形头像：圆形裁剪下仍能看清**白毛 + 小龙角 + 紫色眼睛**。
- 透明头像/表情：至少 256×256；不得有不可见水印和他人署名的擅自移除。
- 半身/全身设定图：优先原创绘制或明确授权的生成/委托资产。
- 暂不放入任何第三方 B 站图片，也不把参考图当成项目正式资产。
